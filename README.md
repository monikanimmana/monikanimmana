### TravelqueYou — AI Travel Planning Platform
> *Rebuilt entirely solo after originating as a hackathon project*

- 🤖 **Shiro AI** — RAG assistant built with pgvector + Gemini AI for trip planning
- 🏗️ **9 modules** — auth, trips, itinerary, budget, packing, destinations, AI, notifications, analytics
- 🗄️ **12 database tables** with relational design and geo-aware queries
- ⚡ Async task processing with **Celery + Redis**
- 🚀 Deployed: **Railway** (backend) + **Netlify** (frontend)

### CivicLens — Geospatial Civic Issue Monitor
> *AI-powered system where citizens report environmental issues with photos + GPS*

- 📍 **PostGIS** for geo-queries — city/village-wise hotspot detection
- 🤖 **Vision API + Gemini** — auto-classifies issue type + severity from photos
- 🔁 Duplicate detection engine + crowd voting priority system
- ⚙️ **Celery + Redis** async AI processing pipeline
- 🗺️ Real-time map dashboard with heatmap visualization
